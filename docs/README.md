# myassistant Documentation

A terminal-based AI coding assistant built on [Agno](https://github.com/agno-agi/agno).

## Guides

| Guide | Description |
|---|---|
| [usage.md](usage.md) | Install, run, and interact with myassistant |
| [configuration.md](configuration.md) | All `context/` config files explained |
| [skills.md](skills.md) | Add and write agent skills |
| [extending.md](extending.md) | Extend tools, override defaults, and customise deeply |

## Quick start

```bash
# Install
uv sync

# Run in current project directory
uv run myassistant

# Run in a specific project
uv run myassistant --project /path/to/project
```

See [usage.md](usage.md) for all options.
